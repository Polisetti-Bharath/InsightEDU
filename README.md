# InsightEDU

**Turn Student Data Into Actionable Insights**

InsightEDU is an academic analytics platform for managing students, subjects, and marks, with every
dashboard, ranking, and report generated by the **MongoDB Aggregation Framework** — not client-side
calculations.

## Tech Stack

- **Frontend:** Next.js 15 (App Router), TypeScript (strict), Tailwind CSS v4, shadcn/ui, Recharts, lucide-react
- **Backend:** Next.js Route Handlers + Server Actions
- **Database:** MongoDB (Atlas in production) via Mongoose
- **Auth:** NextAuth (Auth.js v5) with credentials (email/password) and role-based access (`admin`, `faculty`)
- **Deployment:** Vercel

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy `.env.example` to `.env.local` and fill in the values:

```bash
cp .env.example .env.local
```

| Variable | Description |
| --- | --- |
| `MONGODB_URI` | MongoDB connection string (Atlas in production, or a local/Docker MongoDB for development) |
| `NEXTAUTH_SECRET` | Random secret used to sign session tokens. Generate one with `openssl rand -base64 32` |
| `NEXTAUTH_URL` | The app's base URL (`http://localhost:3000` locally) |

For local development without Atlas, you can run MongoDB in Docker:

```bash
docker run -d --name insightedu-mongo -p 27017:27017 -v insightedu-mongo-data:/data/db mongo:7
```

### 3. Seed the database

Seeds 5 departments, 10 subjects, 100 students, 1000 marks records, and two demo accounts:

```bash
npm run seed
```

Demo accounts created by the seed script:

- **Admin** — `admin@insightedu.app` / `Admin@123`
- **Faculty** — `faculty@insightedu.app` / `Faculty@123`

### 4. Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Roles

- **Admin** — full CRUD on students, subjects, and marks; full analytics access.
- **Faculty** — enters and manages marks, views students/subjects, views analytics and reports.

## Deploying to Vercel

1. Push this repository to GitHub.
2. Import the project in Vercel.
3. Set the environment variables (`MONGODB_URI`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL`) in the Vercel project settings — use a MongoDB Atlas connection string for `MONGODB_URI`.
4. Deploy. Vercel will run `npm run build` automatically.

## MongoDB Aggregation Pipelines

Every analytics endpoint (`/api/analytics/*`) and the corresponding pages (`/dashboard`, `/analytics`) are
powered entirely by MongoDB aggregation pipelines defined in `src/services/analyticsService.ts`, including:

- Dashboard KPIs (`$count`, `$avg`, `$max`, `$min`, `$cond`)
- Student rankings and Top 10 (`$group`, `$avg`, `$sort`, `$limit`)
- Subject performance (`$group`, `$avg`, `$lookup`)
- Weak students (`$match`, `$group`)
- Grade distribution (`$bucket`)
- Department performance (`$lookup`, `$group`)
- Subject failure analysis (`$group`, `$sort`)
- Pass percentage (`$group`, `$cond`)
